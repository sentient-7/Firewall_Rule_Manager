# 🔥 Firewall Rule Manager

A menu-driven Firewall Rule Management System developed in **C** to create, manage, search, sort, update, and delete firewall rules.

## Features
- Add, display, update, and delete firewall rules.
- Search rules using Rule ID, Source IP, Destination IP, and Protocol.
- Sort rules by Rule ID, Priority, Source Port, and Destination Port.
- Dynamically allocate and manage memory for firewall rule records.

## Technologies & Concepts
- **Language:** C
- **Concepts:** Data Structures and Algorithms (DSA), Structures, Dynamic Memory Allocation.
- **Memory Management:** `calloc()`, `realloc()`, `free()`.

## Algorithms Implemented

| Operation | Algorithm |
|---|---|
| Rule ID Sorting | Bubble Sort |
| Priority Sorting | Merge Sort |
| Source Port Sorting | Selection Sort |
| Destination Port Sorting | Insertion Sort |
| Rule ID Searching | Binary Search |
| IP & Protocol Searching | Linear Search |

## Use Case
Simulates an enterprise firewall rule management system, helping network administrators organize, retrieve, and manage firewall configurations efficiently.

**Domain:** Cybersecurity | Network Security | DSA
